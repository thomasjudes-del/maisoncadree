# Maison Cadrée

Public website for **Maison Cadrée**, a renovation and turnkey project-management business serving Nantes, Loire-Atlantique and the Atlantic coast.

Public site: https://maisoncadree.com/

## What the implementation includes

- Responsive public-facing website
- French and English content structure
- Project and service presentation
- Custom visual identity and navigation
- SEO metadata, canonical URLs and hreflang structure
- Structured data for local business discovery
- Social and contact integration
- Static deployment with a custom domain

## Implementation

The site is built as a lightweight static web experience using HTML and CSS, with dedicated asset directories and a custom-domain deployment.

## Why the project matters

It demonstrates rapid execution of a complete small-business web presence: translating a service proposition into positioning, information architecture, responsive design, SEO-ready implementation and a deployable production website.
